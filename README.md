# HTML Component Builder

## 📝 Descrição

O HTML Component Builder é uma ferramenta interativa para criar e personalizar componentes HTML de forma visual. Este projeto permite que usuários sem conhecimento avançado de programação possam criar interfaces web de maneira intuitiva através de uma interface drag-and-drop.

## ✨ Funcionalidades

- **Componentes Pré-definidos**: Adicione títulos, descrições e botões à sua página
- **Editor Visual**: Personalize cada componente com opções intuitivas
- **Visualização em Tempo Real**: Veja as alterações enquanto edita
- **Geração de Código**: Exporte o código HTML gerado
- **Interface Amigável**: Design moderno e responsivo
- **Reordenação por Arrastar**: Organize seus componentes facilmente

## 🛠️ Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces
- **TypeScript**: Superset tipado de JavaScript
- **Tailwind CSS**: Framework CSS para design responsivo
- **Vite**: Build tool e servidor de desenvolvimento
- **Lucide React**: Biblioteca de ícones
- **Context API**: Para gerenciamento de estado

## 🚀 Instalação

```bash
# Clone o repositório
git clone https://github.com/SEU-USUARIO/html-component-builder.git

# Entre no diretório do projeto
cd html-component-builder

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## 📖 Como Usar

1. Clique em um componente na barra lateral para adicioná-lo à prévia
2. Clique em um componente na área de prévia para editá-lo
3. Personalize o componente usando as opções do editor
4. Arraste os componentes para reordenar
5. Visualize o código HTML gerado na aba Código
6. Exporte o código para usar em seu projeto

## 📋 Estrutura do Projeto

```
src/
├── components/      # Componentes da interface
│   ├── editors/     # Editores para cada tipo de componente
│   └── preview/     # Componentes de visualização
├── context/         # Context API para gerenciamento de estado
└── App.tsx          # Componente principal
```
